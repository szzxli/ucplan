How to read this table

  • Each row is one course-to-course articulation from the ASSIST agreement. A community college course can appear in more than one row — taking it once covers each UC course listed.
  • “—” in the UCLA column means the Diablo Valley College course satisfies a requirement without a single one-to-one UC course code in this agreement.
  • Some requirements are satisfied by a sequence of courses or by one of several options. The agreement itself states the exact combination — check it on ASSIST.
  • This page is a planning reference, not an admission decision. Completion of these courses does not guarantee admission.
